# Aleksandra Matlak — portfolio

A buildless portfolio: seven HTML pages, one stylesheet, local images. No dependencies, JavaScript, accounts, tracking or installation.

## Open it

Open `index.html` in your browser. All local pages and images work from disk. Steam, YouTube, itch.io, email and the full Google Docs sample need an internet connection.

## Put it on GitHub Pages

1. Keep a copy of your existing site.
2. Extract this ZIP. Upload the CONTENTS of the extracted folder into the same repository directory where your current `index.html` lives. Replace that file; keep `styles.css`, the other HTML files and the `assets` folder beside it. Do not upload only the ZIP or nest the new files inside another folder.
3. Commit the changes. Your existing GitHub Pages configuration can continue to serve that directory.

## Edit it

- `index.html`: introduction, project summaries, writing links and About.
- Each project has its own clearly named HTML file.
- `styles.css`: shared styling. Colours are defined at the top; the small-screen layout is near the end.
- `assets/`: local images and the favicon. Replace an image with the same filename to update it.
- Navigation and the footer are plain HTML repeated on each page. Update all seven pages when changing those shared links. There is deliberately no template/build tool to install.
